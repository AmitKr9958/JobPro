# JobPro\n\nFree-first Chrome MV3 job assistant inspired by modern job copilots. It provides cross-page autofill, application-question answers, resume tailoring, job matching, job discovery and a local application tracker.\n\n## Current capabilities\n\n- Autofill across normal web pages with semantic field matching, labels, React/native setters, shadow DOM and cross-origin iframe content scripts.\n- Resume PDF attachment where the site exposes a normal file input.\n- Saved application answers and reusable profile data.\n- Supabase email/password authentication and offline-first local storage.\n- AI answer/tailor/cover-letter/match-score actions through a Supabase Edge Function.\n- Job discovery through Adzuna and Remotive through a Supabase Edge Function.\n- Application tracker. JobPro never clicks a final Submit button automatically.\n\n## Free setup\n\n1. Create a free Supabase project.\n2. In Supabase SQL Editor run `supabase/migrations/001_jobpro.sql`.\n3. Enable Email auth in Authentication -> Providers.\n4. Copy the project's URL and publishable/anon key.\n5. Load the extension from `chrome://extensions` -> Developer mode -> Load unpacked.\n6. Open JobPro -> Settings and enter the Supabase URL and publishable/anon key. Never put a service-role key in the extension.\n7. Deploy Edge Functions: `supabase functions deploy ai` and `supabase functions deploy fetch_jobs`.\n8. Set server-side secrets only: `supabase secrets set OPENROUTER_API_KEY=YOUR_GEMINI_KEY`, `supabase secrets set ADZUNA_APP_ID=YOUR_ADZUNA_ID`, `supabase secrets set ADZUNA_APP_KEY=YOUR_ADZUNA_KEY`.\n9. The free AI path uses OpenRouter's free-model router through the Supabase Edge Function. Provider availability and free quotas can change.\n\n## AI privacy\n\nBefore the first AI request JobPro asks for consent. AI requests contain job text plus resume/profile facts needed for the task. Phone, address, government IDs and salary are excluded by the extension. Do not paste those values into your resume text.\n\n## Cross-page behavior\n\nThe content script uses `<all_urls>` and `all_frames`. It works on ordinary HTTP/HTTPS pages. Browser-controlled pages such as `chrome://`, Chrome Web Store pages and some browser-internal surfaces cannot be injected by any normal extension.\nSites with closed shadow DOM, canvas-only forms, custom file pickers, anti-automation controls or highly unusual virtualized widgets can still require manual input. JobPro does not bypass site security controls.\n\n## Testing\n\nRun: `npm install` then `npm test`.\nThe existing six fixture tests cover Greenhouse, Lever, Workday, Ashby, a plain form and a React-style controlled input.\n\n## Safety\n\nJobPro is an assistant, not an auto-submit bot. Review filled fields and AI output before submitting an application yourself.

## Existing Supabase projects

The migration uses `jobpro_` table names and a private `jobpro-resumes` storage bucket so it does not collide with pre-existing application tables in an older Supabase project. The deployed Edge Functions are `ai`, `fetch_jobs`, and `delete_data`. Configure `OPENROUTER_API_KEY`, `ADZUNA_APP_ID`, `ADZUNA_APP_KEY`, and `SUPABASE_SERVICE_ROLE_KEY` as server-side Supabase secrets before using cloud AI/job ingestion.
